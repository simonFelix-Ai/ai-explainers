# ai-explainers

3Blue1Brown-style explainer videos for AI architectures and papers, made with
[Manim Community](https://www.manim.community/). Each directory holds one topic: the rendered
videos, subtitles, thumbnails, upload notes and the full animation source.

| Directory | Topic | Versions |
| --- | --- | --- |
| [`proxy-former/`](proxy-former/) | **ProxyFormer**: a dual-stream proxy architecture for ultra-long context and high-resolution generation ([arXiv:2608.23463](https://arxiv.org/abs/2608.23463)) | 中文 7:46 · English 6:36 |

Each topic directory has its own README with the structure, sources and rebuild instructions.
