# Neural Sudoku: teaser MV

A 45-second cinematic teaser for upcoming work on **neural networks solving hard discrete problems**.
The 3D scene is built in **three.js** (glass board, bloom, instanced candidate orbs, attention arcs,
a backtracking search tree) and captured frame by frame in headless Chromium. Captions, film grade
and a procedurally synthesized soundtrack are added in Python. There are no stock assets and no
third-party music.

| File | |
| --- | --- |
| `neural_sudoku_teaser.mp4` | Final teaser, 1920×1080, 30 fps |
| `web/index.html`, `web/scene.js` | three.js scene; `renderAt(t)` is a pure function of time |
| `web/puzzle.json` | Puzzle, verified unique solution, settle order (generated by `sudoku.py`) |
| `render.mjs` | Headless Chromium frame capture (playwright-core + SwiftShader WebGL) |
| `post.py` | Captions, title card, vignette, grain, letterbox, audio mux |
| `music.py` | Soundtrack synthesizer (A minor, 96 BPM, 18 bars) |
| `sudoku.py` | Solves the puzzle and proves the solution is unique |

## The puzzle

Arto Inkala's 2012 puzzle, widely publicised as "the world's hardest sudoku" (21 clues). `sudoku.py`
solves it, checks every constraint, and proves the solution is unique before the animation uses it.

## Timeline (96 BPM, one bar = 2.5 s)

| Time | Scene |
| --- | --- |
| 0:00 | Glass board, 21 glowing clues: *The world's hardest sudoku · 21 clues, one answer* |
| 0:05 | Classic search: a tree of branches grows over the board; almost all die red, one gold path survives |
| 0:12.5 | Darkness: *What if a neural network could reason through it?* |
| 0:15 | Neural phase: nine candidate orbs per cell; impossible digits fade, rivals rise and fall, winners drop into the tiles as gold digits; arcs link each deciding cell to its 20 row/column/box peers |
| 0:32.5 | Verification: every row, column and box lights up in turn, with one chime each |
| 0:37.5 | Title card: **COMING SOON** |

The neural phase is an **artistic visualization**, not a trace of a specific model. The captions
deliberately avoid claims about method or accuracy.

## Customize the title card

Edit the constants at the top of `post.py` (`TITLE`, `SUBTITLE`, `TAGLINE`, `BYLINE`, ...). Then re-run
only the post step; the 3D frames don't need re-rendering.

## Rebuild

```bash
npm install                                   # three + playwright-core
python3 sudoku.py                              # writes web/puzzle.json
node render.mjs --frames frames --fps 30       # ~1–3 s/frame with software WebGL
pip install numpy scipy opencv-python-headless pillow
python post.py --frames frames --out neural_sudoku_teaser.mp4
```

`render.mjs` expects Chromium at `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`; set `CHROME=/path/to/chrome`
to use another one. Ranges can render in parallel with `--start` / `--end`.
